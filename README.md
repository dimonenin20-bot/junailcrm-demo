# 💅 JuNailCRM — Демо-сайт веб-панелі ательє краси (Unslopped Edition)

Повністю автономний, інтерактивний демонстраційний сайт адмін-панелі **JuNailCRM v2.4.7**, створений за стандартами **Unslop** (тихий графітовий хром, тактильні перемикачі, 4px сітка, відсутність AI-градієнтів та емодзі-слопу).

---

## 🌟 Основні можливості демо-панелі

1. **🗓 Розклад & Записи (Appointments):**
   - Перегляд активних записів із фільтрами статусів (*Підтверджено, Очікує, Завершено*).
   - Кнопка **«📝 Заповнити бриф»** навпроти кожного запису.
2. **📋 Повноцінний Бриф візиту (Visit Brief Modal):**
   - Точна копія нативного Android-діалогу `VisitBriefDialog.kt`.
   - Вибір стану покриття, типу пластини, стану кутикули, базового гелю, форми та довжини.
   - Фіксація улюбленого напою клієнтки та медичних нотаток (алергій).
   - **Автоматичне списання матеріалів (BOM):** база (0.5 мл), топ (0.4 мл), одноразова пилочка (1 шт), апельсинова паличка (1 шт).
   - При збереженні: матеріали списуються зі складу, візит стає «Завершено», а дохід фіксується у фінансах!
3. **👥 Клієнтська база:**
   - 5 передзавантажених детальних клієнток з історією візитів, сумами та вподобаннями.
4. **📦 Склад матеріалів:**
   - Моніторинг залишків у мл/шт з індикатором критичного залишку.
5. **💰 Фінансова аналітика:**
   - Автоматичний розрахунок денного та місячного обороту, собівартості матеріалів та чистого прибутку майстра.
6. **📱 Генератор Instagram Stories (1080x1920):**
   - Рендеринг на HTML5 Canvas готової естетичної картки з вільними віконцями та кнопка завантаження PNG в 1 клік.
7. **💾 LocalStorage + Скидання:**
   - Усі зміни зберігаються локально в браузері. Кнопка у футері сайдбару миттєво повертає початковий демо-стан.

---

## 🚀 Як відкрити локально

Просто двічі клацніть на файл `index.html` або запустіть будь-який локальний сервер:
```bash
python -m http.server 8080
```
І відкрийте в браузері: `http://localhost:8080`

## ☁️ Як вивантажити на GitHub (в окремий репозиторій)

1. Створіть новий порожній репозиторій на [github.com/new](https://github.com/new) з назвою `junailcrm-demo`.
2. У папці `junailcrm-demo` виконайте:
   ```bash
   git init
   git add .
   git commit -m "feat: initial release of JuNailCRM unslopped web demo"
   git branch -M main
   git remote add origin https://github.com/<ваш-юзернейм>/junailcrm-demo.git
   git push -u origin main
   ```
3. У налаштуваннях репозиторію (**Settings ➔ Pages**) виберіть гілку `main` і натисніть **Save**.
4. Сайт стане доступний за адресою: `https://<ваш-юзернейм>.github.io/junailcrm-demo/`
